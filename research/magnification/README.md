# Magnification pass — 2026-08-15 (first pass)

Crops from the original scans (1600×1081), upscaled 5–12× with contrast/sharpening, made
while working issue #20. The scans' resolution is the hard limit throughout: several
targets sit at 2–6 original pixels of letter height and cannot be recovered without a
**high-resolution re-scan of the original slides** — which is now the single action that
would unlock the most (see "blocked by resolution" below).

## Blocked by resolution — the re-scan case

VN-0014's patch lettering, VN-0009's inscriptions, and both VN-0020 name tapes would all
plausibly resolve from a 4000dpi slide scan. That makes "do the original slides still
exist, and can we re-scan the high-value ones?" (already a breakfast housekeeping
question) a research action with a concrete payoff list.
