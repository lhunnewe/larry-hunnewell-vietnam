# Sources

One JSON file per source, following the `sources` schema in `src/content.config.ts`.

Source priority for this project, highest first: official U.S. Army and National Archives records (morning reports, operational reports, personnel records, after-action reports), contemporary Stars and Stripes issues and Vietnam-era newspapers, official and period military maps, contemporary photographs, oral histories, official casualty databases, unit histories, then secondary histories.

Timeline events and other records cite sources by the source file's id (its filename without `.json`).
